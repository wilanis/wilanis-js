# X252

- **Family:** X -- plugin rules, @schedule (@wilanis/plugin-schedule)
- **Status:** live, since 0.1.0
- **Made in:** `packages/plugin-schedule/src/rules.ts`
- **Proved by:** `packages/runtime/test/sabotage-schedule.test.ts` (`X252 an in nothing fills: nothing arrives on a tick`)

## Refuses when

A scheduled trigger declares `in` and writes no `fire.in`. Nobody is calling on a tick, so the input would be
`request.body`, which this kind never hands, and every tick would be refused at the edge. The refusal sits at `in`.

## Example

Give the planted nightly trigger an `in`:

```
X252  @features/hello/edge/nightly-greeting.trigger.json#in
    a scheduled trigger declares in and no fire.in: nobody is calling, so the input would be request.body, which this kind never hands, and every tick would be refused at the edge
    → write fire.in reading request.scheduled, or fire an operation that takes nothing and drop in
```

## Fix

Write `fire.in` over what a tick does hand, `request.scheduled`, or drop `in` and fire an operation that takes
nothing.
