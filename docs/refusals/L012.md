# L012

- **Family:** L -- layers, effects and visibility
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/graph.ts`
- **Proved by:** `packages/runtime/test/sabotage-attempts.test.ts` (`L012 a domain graph that retries a call or
  bounds one`)

## Refuses when

A domain graph's `run` or `map` node declares `retry` or `timeoutMs`. The domain says what is done; how long a call
may take and how often it is tried is the data layer's, where the effect runs. Each word is its own refusal, at
`nodes/<id>/retry` or `nodes/<id>/timeoutMs`.

## Example

Give the `registered` node of the customers `register-customer` domain graph a retry:

```
L012  @features/customers/domain/register-customer.graph.json#nodes/registered/retry
    domain graph declares retry on '@customers/domain/customer.port.json#register'
    → the domain says what is done, the data layer how: write retry in the binding that meets the operation, or in the data graph that runs the effect
```

A `timeoutMs` reads `domain graph declares timeoutMs on '<run>'` at `nodes/<id>/timeoutMs`, with the same hint.

## Fix

Remove the word from the domain graph and write it where the effect runs: on the binding operation that meets the
domain operation, or on the data graph's node that runs the native operation. A retry there is judged by G017, G018
and G019.
