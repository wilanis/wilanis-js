# S001

- **Family:** S -- scenarios
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/scenarios.ts`
- **Proved by:** `packages/runtime/test/sabotage-unproved.test.ts` (`S001 a scenario that names a trigger the tree does not have`)

## Refuses when

A scenario's `trigger` names no trigger of the tree. A scenario is a recorded run of one trigger, replayed by
`wilanis regress`; with the trigger gone there is nothing to replay it against. The refusal sits at `trigger`.

## Example

```
S001  @scenarios/probe.scenario.json#trigger
    scenario names unknown trigger '@customers/edge/no-such.trigger.json'
    → wilanis ls trigger
```

## Fix

Point `trigger` at the trigger the scenario records (`wilanis ls trigger` lists them), which is usually a rename or a
move the scenario did not follow. If the trigger was removed on purpose, delete the scenario, or record the new one
with `wilanis fuzz`.
