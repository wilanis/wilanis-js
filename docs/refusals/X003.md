# X003

- **Family:** X -- plugin rules, @http (@wilanis/plugin-http)
- **Status:** live, since 0.1.0
- **Made in:** `packages/plugin-http/src/rules.ts`
- **Proved by:** `packages/runtime/test/sabotage-project.test.ts` (`X003 a throttle that lets nothing through`)

## Refuses when

An http connection's `settings.throttle` holds a limit that could never let a request through. `concurrency`, the
number of requests in flight at once, must be a whole number of 1 or more; `perSecond`, the number of requests
started per second, must be above 0. Each is refused on its own, at `settings/throttle/concurrency` or
`settings/throttle/perSecond`. A throttle member that is not a number at all is C002's, since the connection kind
declares its types; X003 judges what a type cannot say.

## Example

Allow the customers API no requests in flight:

```
X003  @connections/customers-api.connection.json#settings/throttle/concurrency
    throttle.concurrency is 0; it is the number of requests in flight at once, a whole number of 1 or more
    → set it to 1 or more, or drop it for no limit
```

A `perSecond` of `-1` is refused at `settings/throttle/perSecond`, saying it is the number of requests started per
second, above 0, with the hint `set it above 0, or drop it for no limit`.

## Fix

Set the limit to one a request can pass (`concurrency` a whole number of 1 or more, `perSecond` above 0), or delete
the member: a throttle without it does not limit that.
