# D004

- **Family:** D -- documents
- **Status:** live, since 0.1.0
- **Made in:** `packages/core/src/documents.ts`
- **Proved by:** `packages/runtime/test/sabotage-unproved.test.ts` (`D004 a trigger kind authored in a tree instead of shipped by a plugin`)

## Refuses when

A tree holds a document of a kind only a plugin ships: `plugin`, `trigger-kind`, `connection-kind` or `codec`. Those
say what a plugin grants and what its code implements; one written in a tree would describe code nobody wrote. There
is no `at`.

## Example

Author a trigger kind inside a feature:

```
D004  features/hello/edge/mine.trigger-kind.json
    trigger-kind documents are shipped by plugins, never authored in a tree
    → remove the file; wilanis ls trigger-kind shows the ones a plugin grants
```

## Fix

Remove the file and use a kind a plugin grants (`wilanis ls <kind>`), naming that plugin under `project.json →
plugins` if it is not there yet. If no plugin grants what is needed, the kind belongs in a plugin package, not in the
tree.
