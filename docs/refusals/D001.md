# D001

- **Family:** D -- documents
- **Status:** live, since 0.1.0
- **Made in:** `packages/core/src/validate.ts`
- **Proved by:** `packages/runtime/test/sabotage-project.test.ts` (`D001 a document that breaks its schema`, `D001 a $schema in neither the published nor the alias form`)

## Refuses when

A document does not conform to the JSON Schema of its kind, or cannot say which kind it is. Three forms:

- the file parses but is not a JSON object (no `at`);
- its `$schema` names no wilanis kind in either form, the published URL or the short `@wilanis/<kind>.schema.json`
  (`at` is `$schema`, and the hint lists every kind). A `$schema` at the tag of an IR version this runtime does not
  read is D013 instead, judged before this;
- it names a kind and breaks that kind's schema: one refusal per deviation, at the path where it sits, in the
  schema's own words (`unknown property 'returnz'`, `must be object`, a pattern the value must match), with the
  schema's URL as the hint.

Inside a graph, a path into `nodes` names the node by its `id` (`nodes/outcome/in`), as the checker's own refusals
do, so a reorder moves no `at`; a node without an id keeps its index. The rule holds a tree's documents and what a
plugin ships alike. A document that fails its schema is not registered, so what names it is refused too, usually as
R001.

## Example

Misspell a member of an operation in the customers port:

```
D001  features/customers/domain/customer.port.json#operations/listAll
    unknown property 'returnz'
    → see https://raw.githubusercontent.com/wilanis/wilanis-js/main/packages/core/schemas/port.schema.json
R001  @project.json#profiles/live/bindings
    profile 'live' names unknown port '@customers/domain/customer.port.json'
    → wilanis ls port
```

Write a number where a graph's node takes its inputs, and the node is named by its id:

```
D001  features/customers/data/get-row.graph.json#nodes/outcome/in
    must be object
    → see https://raw.githubusercontent.com/wilanis/wilanis-js/main/packages/core/schemas/graph.schema.json
```

## Fix

Edit the document at `at` until it conforms; the schema the hint links describes every property. For a `$schema`
refusal, point `$schema` at the kind the file is, in either form. Fix the D001 before the refusals below it: the
R001s naming the same document go once it registers.

## History

- 0.1.0: introduced.
- 0.1.0: `at` inside a graph names a node by its `id` rather than its index (RFC 0019).
- 0.1.0: a `$schema` at the tag of another IR version, `schemas-v2`, is D013 and no longer this (RFC 0008).
