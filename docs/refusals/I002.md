# I002

- **Family:** I -- invariants
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/invariants.ts`, `packages/compiler/src/check/invariant-holds.ts`
- **Proved by:** `packages/runtime/test/sabotage-invariants.test.ts` (`I002 over naming a native operation, and proves naming a path no guard hands`, `I002 holds.on naming an edge shape, and R001 naming no shape at all`)

## Refuses when

An invariant names something it cannot constrain. Three forms. An access invariant's `over` names an operation of a
native port (`over names '<op>', an operation of native port '<port>'`, at `access/over/<index>`): an invariant
gates domain ports, and a native one is reached through a binding. Its `requires.proves` names a path no trigger kind
or guard hands (`requires.proves names <path>: ...`, at `access/requires/proves/<index>`), the judgement A001 makes
of a policy's `proves`. A field invariant's `holds.on` names a shape that is not a core shape (`holds.on names
<layer> shape '<path>'`, at `holds/on`): an edge shape is the trigger's to judge. An operation or shape that does
not exist is R001, and one the invariant may not see is L005.

## Example

```
I002  @features/customers/domain/writes-are-for-registrars.invariant.json#access/over/0
    over names '@http/http.port.json#request', an operation of native port '@http/http.port.json'
    → an invariant gates domain ports; a native port is reached through a binding
```

The proves form:

```
I002  @features/directories/domain/the-session-is-the-callers.invariant.json#access/requires/proves/0
    requires.proves names request.nope: no trigger kind hands request.nope
    → wilanis describe the guarding plugin shows what it hands
```

## Fix

Name the domain operation whose binding reaches the native one, a path the guard hands (`wilanis describe` on the
guarding plugin lists `request.principal`, `request.session`, `request.challenge`), or the core shape the edge shape
is made from. An I003 beside the first form, since nothing reaches a native operation through a trigger, goes with
the same edit; a field invariant moved off its shape takes the guards and their `invariant` reason with it, so T006
follows on every trigger that mapped it until the shape is put back.
