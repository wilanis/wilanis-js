# T007

- **Family:** T -- triggers
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/triggers.ts`
- **Proved by:** `packages/runtime/test/plugin-packages.test.ts` (`T007 a trigger kind whose correlation names no field of its own context`)

## Refuses when

A trigger kind's `correlation` names a path its own context does not hand. The runtime copies that value into a run's
trace opaquely, to correlate the run with its caller's trace, so a path with no field behind it would correlate
nothing and say so nowhere. The document refused is the kind, which a plugin ships, at `correlation`.

## Example

Break the http plugin's route kind so that its correlation reads `traceparent` rather than `headers.traceparent`
(the context in the message is trimmed here):

```
T007  @http/http.trigger-kind.json#correlation
    correlation reads request.traceparent, which this kind's context does not hand: no field 'traceparent' in {method: string, path: string, headers: {, ...}, ...}
    → name a field of context, as in headers.traceparent, or remove correlation
```

## Fix

Name a path into the kind's `context`, as in `headers.traceparent`, or remove `correlation`. The edit is to the
plugin's document, so a tree that meets this from a plugin it did not write has found a bug in that plugin.
