# G007

- **Family:** G -- graphs
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/graph-whole.ts`
- **Proved by:** `packages/runtime/test/sabotage-unproved.test.ts` (`G007 a cycle: a node that reads itself`)

## Refuses when

The graph's nodes depend on one another in a loop, through what they read and through routing (a routed node runs
after its switch). A graph is dataflow: a node runs when every input it reads is ready, so a node that waits on itself,
directly or through others, never runs. The message spells the cycle (`cycle: a → b → a`) and the refusal sits at
the node the walk found it from, `nodes/<id>`.

## Example

Make the first node of `greet` read its own answer:

```
G007  @features/hello/domain/greet.graph.json#nodes/said
    cycle: said → said
    → break the cycle: a graph is a dataflow, so one of these edges must read something earlier
```

In this sabotage a G006 at `nodes/said/in/self` comes first, because the input added to make the loop is also one
`@std/text.port.json#fill` does not take.

## Fix

Find the edge in the cycle that should read something earlier: `in`, a constant, or a node before the loop. A repeat
over a list is a `map`, not a loop. A switch that routes to a node which reads the switch's own answer back is the same
cycle.
