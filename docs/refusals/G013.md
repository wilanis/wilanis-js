# G013

- **Family:** G -- graphs
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/graph.ts`
- **Proved by:** `packages/runtime/test/sabotage-unproved.test.ts` (`G013 a constant whose value is not of its type`)

## Refuses when

A constant's `value` does not conform to the type it declares under `constants/<name>/type`. A constant is read as
`{{const.<name>}}` with that type, so the value has to be one. The message names the constant, the type, and where
the value fails (`$: expected string`); the refusal sits at `constants/<name>/value`.

## Example

Give `greet`'s `who` a number:

```
G013  @features/hello/domain/greet.graph.json#constants/who/value
    constant 'who' does not conform to string: $: expected string
    → write a value of that type, or change the constant's type
```

## Fix

Write a value of the declared type, or change the type if the value is what was meant; every read of the constant is
then typed by the new type.
