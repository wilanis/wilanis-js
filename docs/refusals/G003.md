# G003

- **Family:** G -- graphs
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/graph-reads.ts`, `packages/compiler/src/check/inputs.ts`
- **Proved by:** `packages/runtime/test/sabotage.test.ts` (`G003 a deep path that does not exist`)

## Refuses when

A value reads something that cannot be typed: a field the shape of `in` does not have, a constant not declared, a
path deeper than the value holds, a node that is not in the graph or does not run before the reader, or a name that is
neither a root nor an entry of the document's `reads`. The message is what the type walk found (`no field 'emaill'
in ...`, `'<name>' is not in, const, a node that runs before this one, or a name under reads`) and the refusal sits
at the input that reads it, `nodes/<id>/in/<field>`. In a graph it is made in `graph-reads.ts`; a binding's
delegation reads through `inputs.ts` and is refused at `operations/<name>/in/<field>` the same way.

## Example

Misspell a field of `in` in `register-customer`:

```
G003  @features/customers/domain/register-customer.graph.json#nodes/registered/in/email
    no field 'emaill' in @features/customers/domain/CustomerDraft.shape.json
    → read in, const, or a node that runs before this one
```

A G008 on `in` comes with it: the field the typo meant is now read by nothing. Read a name nothing binds and the hint
changes to the entry that would make it a read of the request:

```
G003  @features/customers/data/create-row.graph.json#nodes/posted/in/headers
    x-forwarded-user-agent: 'caller' is not in, const, a node that runs before this one, or a name under reads
    → to read the request, bind the name: "reads": { "caller": "@<feature>/edge/<file>.resolvers.json#caller" }
```

## Fix

Correct the path to one the value holds (`wilanis describe` on the shape lists its fields), or name the node that
answers it. A name meant as a read of the request is bound under the document's `reads` to a resolver of an edge
`resolvers` document, as the hint spells it; a data graph never reads the request directly. A name that is a
misspelled node id is a typo, and binding it would only trade this refusal for another.
