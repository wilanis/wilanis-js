# D008

- **Family:** D -- documents
- **Status:** live, since 0.1.0
- **Made in:** `packages/core/src/placement.ts`
- **Proved by:** `packages/runtime/test/sabotage.test.ts` (`D008 a port outside the domain layer`, `D008 a connection outside connections/`, `D008 a shape whose declared layer contradicts the directory it sits in`)

## Refuses when

A document is not where its kind lives. The directory is the layer: `edge/` speaks the world, `domain/` holds the
business rules, `data/` translates and carries the effects, and the checker reads a document's role off its path.
`HOME` in `placement.ts` says where each kind is at home: a trigger, policy or resolvers document in `edge/`; a port
or invariant in `domain/`; a binding or store in `data/`; a graph in `domain/` or `data/`; a shape in `edge/` or
`domain/`; a connection under the tree's `connections/`, a scenario under `scenarios/`. The forms:

- a kind with a top-level directory outside it;
- a kind that lives in a feature, outside any feature;
- a document inside a feature but in no layer directory, or in a layer its kind may not live in;
- a shape whose `layer` disagrees with the directory it sits in (`at` is `layer`): `"layer": "edge"` belongs in
  `edge/`, anything else in `domain/`.

The hint says why the kind lives where it does and where to move it. For a kind with two layers it names the first
of them (`domain/` for a graph, `edge/` for a shape), which is a guess: the right one is the author's to say.

## Example

Move the customers port into the edge layer:

```
D008  features/customers/edge/customer.port.json
    a port may not live in the edge layer
    → a domain port is the contract the business offers; move it to features/customers/domain/customer.port.json
```

Give a domain shape an edge `layer`:

```
D008  features/customers/domain/Customer.shape.json#layer
    shape declares layer 'edge' but sits in domain/
    → a shape's layer is where it lives; move it to features/customers/edge/, or set "layer": "core"
```

## Fix

Move the file where the hint says when its kind has one home. For a graph or a shape, decide which layer it belongs
to first: a data graph moved to `domain/` only trades D008 for L002. For the shape form, either move the file or set
`layer`, whichever was meant. A misplaced document is not registered, so the R001s naming it go with the move.
