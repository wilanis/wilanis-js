## Refuses when

The edge reaches past the domain, or a domain contract fixes a value. Three forms:

- a trigger's `fire.run` names an operation of a native port (at `fire/run`): a trigger fires a domain port, and the
  port's binding reaches the native operation;
- a policy's `decide.run` names an operation of a native port (at `decide/run`): a policy decides through a domain
  port, for the same reason;
- a domain operation marks one of its `accepts` fields `static` (at `operations/<name>/accepts/<field>`): static
  fields belong to native contracts, and a value fixed for a call is the binding's to write.

## Example

Point the customers `digest` trigger at a native operation:

```
L006  @features/customers/edge/digest.trigger.json#fire/run
    trigger fires native operation '@std/list.port.json#count'
    → a trigger fires a domain port; the port's binding reaches the native operation
```

A policy reads `policy decides through native operation '<run>'`, with the hint `a policy decides through a domain
port; the port's binding reaches the native operation`. A `static` on the customers port's `get` reads:

```
L006  @features/customers/domain/customer.port.json#operations/get/accepts/id
    domain operation 'get' marks 'id' static -- static fields belong to native contracts; a binding fixes values
    → drop static, or fix the value in the binding
```

## Fix

For a trigger or policy: declare the operation on a domain port, bind it in a feature's data layer to the native
operation (a delegation or a data graph), and fire or decide through the domain operation. For `static` on a domain
operation: drop it, and write the fixed value in the binding's `in` where the operation is met.
