## Refuses when

A document names something the tree does not have. Every reference is a path, `@`-rooted through an alias, a
plugin's root or `@features`/`@connections`, and it must resolve to a registered document of the kind the field
expects. The forms, each at the field that names it:

- an operation, `path#operation`, whose port is unknown, which is not written as `path#operation`, or whose port has
  no such operation (the message lists the ones it has) -- a graph's `run`, a trigger's `fire/run`, a policy's
  `decide/run`, a binding's delegation, an invariant's `over`; the hint is `wilanis ls port`;
- a type: a shape that is not there, or a string that is not a type (`wilanis ls shape`);
- a binding's `port`, a profile's port or binding, a binding operation's `graph`;
- a trigger's `kind`, a connection's `kind`, a store's `connection`;
- a policy named by a trigger, an invariant or a store's view, a resolvers document named under `reads`, the shape an
  invariant `holds` on.

A document that was refused before it registered (D000, D001, D008, D009) is unknown to everything that names it, so
R001 is often the shadow of a refusal about the named file; and a node whose operation is unknown gives nothing to the
nodes that read it, which then refuse as G011 or G005.

## Example

Misspell the operation the get-row graph runs:

```
R001  @features/customers/data/get-row.graph.json#nodes/fetched/run
    port '@http/http.port.json' has no operation 'requst' (operations: request)
    → wilanis ls port
G011  @features/customers/data/get-row.graph.json#nodes/outcome/rules/0/when
    rule 0: 'status' is not an input of this node (inputs: none)
    → write when as an expression over this node's inputs
```

Name a policy that is not there:

```
R001  @features/hello/edge/hello-gated.trigger.json#policies/0
    unknown policy '@access/edge/nope.policy.json'
    → wilanis ls policy
```

## Fix

Correct the reference to a document the tree has; the command in the hint lists what there is of that kind, and the
message names the operations a port does have. When the named document exists but was itself refused, fix that
refusal instead. The refusals below an R001 in the same file are usually its shadow and go with it; check again
before touching them.
