# C017

- **Family:** C -- connections, settings and stores
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/profiles.ts`
- **Proved by:** `packages/runtime/test/sabotage-profiles.test.ts` (`C017 two profiles each marked default`)

## Refuses when

More than one profile under `project.json → profiles` says `"default": true`. The default profile is the one a start
runs when neither `--profile` nor `WILANIS_PROFILE` names one, so there can be at most one; with two, the tree does
not say which place it runs in. The refusal names every profile marked default and points at the `default` of the
second. A tree that declares profiles and marks none default is not refused here; its start must name a profile.

## Example

Mark `production` the default beside `live`:

```
C017  @project.json#profiles/production/default
    profiles 'live', 'production' are each marked default; a start that names no profile runs one
    → one profile is the default; the others are named with --profile
```

## Fix

Keep `"default": true` on the one profile a bare `wilanis start` should run and remove it from the others, which are
then started with `--profile <name>`.
