# X107

- **Family:** X -- plugin rules, @auth (@wilanis/plugin-auth)
- **Status:** live, since 0.1.0
- **Made in:** `packages/plugin-auth/src/timeout.ts`
- **Proved by:** `packages/plugin-auth/test/timeout.test.ts` (`refuses 30 days, which Node would fire after 1 ms,
  aborting every request to the issuer at once`)

## Refuses when

A connection of kind `@auth/oidc.connection-kind.json` says a `timeoutMs` above 2147483647 (2^31 - 1 ms, about 24.8
days). A request for the issuer's discovery document or for a token is given up on a Node timer after `timeoutMs`,
and Node fires a timer set longer than that after 1 ms. So every such request would be aborted at once, and nobody
could sign in through that issuer. The refusal sits on the connection at `settings/timeoutMs`.

## Example

Give an OIDC issuer's connection a timeout of 30 days:

```
X107  @connections/issuer.connection.json#settings/timeoutMs
    timeoutMs is 2592000000; it is the most a request to the issuer may take, in milliseconds, and a Node timer waits at most 2147483647 ms (about 24.8 days): a longer one fires after 1 ms, so every request would be aborted at once
    → set it to 2147483647 or less, or drop it for the default of 10000
```

## Fix

Write a `timeoutMs` of 2147483647 or less, or delete it for the default of 10000 ms.
