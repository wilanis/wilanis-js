# D003

- **Family:** D -- documents
- **Status:** live, since 0.1.0
- **Made in:** `packages/core/src/documents.ts`, `packages/core/src/load.ts`
- **Proved by:** `packages/runtime/test/sabotage-unproved.test.ts` (`D003 the project document somewhere other than the root`)

## Refuses when

A document of a kind with one fixed place is somewhere else. A tree has one project document, `project.json` at its
root, and each feature one manifest, `features/<name>/feature.json`. Three forms: a project document anywhere but
the root; a feature document anywhere but its feature's `feature.json`; and a `project.json` at the root whose
`$schema` names another kind. There is no `at`.

## Example

Plant a second project document inside a feature:

```
D003  features/hello/elsewhere.json
    the project document is project.json at the root
    → move it to project.json, or change its $schema to the kind this file is
```

## Fix

Move the document to its one place, as the hint says, or, when the file was meant to be another kind, correct its
`$schema`. A tree never holds two project documents: fold what the second one says into `project.json`.
