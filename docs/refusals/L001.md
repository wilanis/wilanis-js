# L001

- **Family:** L -- layers, effects and visibility
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/judge.ts`
- **Proved by:** `packages/runtime/test/sabotage-unproved.test.ts` (`L001 a core shape that declares unknown`)

## Refuses when

A type written in the tree names something its layer may not speak. `Judge.checkLayer` walks every type that a
shape's fields, a domain operation's `accepts` and `returns`, a graph's `in` and `out`, a trigger's `in`, `out` and
settings, and a call site's typed inputs name, and refuses three things:

- a type variable (`$Params`, `$I`) or the word `type`, which belong to native contracts only: a native shape
  declares its variables and binds them at its call site, so a shape of this tree naming one binds nothing;
- `unknown` in the core layer, which only edge shapes and native contracts may declare;
- a shape of the other layer: core speaks core shapes, and an edge shape composes edge shapes only.

The message names what declared the type (`shape '<path>'`, `in`, `out`, `<operation>.returns`, an input), and `at`
points at the field or member that holds it.

## Example

Give the hello feature's core `Greeting` shape a field of type `unknown`:

```
L001  @features/hello/domain/Greeting.shape.json#fields/greeting
    shape '@features/hello/domain/Greeting.shape.json' declares unknown -- only edge shapes and native contracts may
    → name the fields, or keep the value at the edge
```

Typed `$Params` instead, the same field reads `uses '$Params' -- that belongs to native contracts only`, with the
hint `name a shape of this tree, or a scalar type`. A core type naming an edge shape reads `names edge shape '<path>'
from the core layer` and hints `core speaks core shapes; a trigger or binding translates edge to core`.

## Fix

Name the fields, or a scalar type, where the value has a shape; keep a value whose shape is not known at the edge, in
an edge shape, and let the trigger or the binding translate it into a core shape. A type variable is never written in
a tree: the native contract binds it where it is called. Where a core document names an edge shape, move the
translation to the trigger or binding, or declare a core shape of the fields it needs.
