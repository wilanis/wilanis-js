# D011

- **Family:** D -- documents
- **Status:** live, since 0.1.0
- **Made in:** `packages/core/src/contracts.ts`
- **Proved by:** `packages/runtime/test/resolves.test.ts` (`a field that resolves a type but is not static, since a resolved type is read before anything runs`, `a key taken by an input the operation has not got`)

## Refuses when

A port document a plugin ships says, in an input's `resolves`, where a type variable comes from in a way it cannot
mean. `resolves` binds a variable such as `$T` from a path into the document the input names
(`collections[collection].of`), and it is read before anything runs. So the input that resolves must be `static`,
and every key a segment takes (`[collection]`) must be another input of the same operation, and a static one. A path
outside the grammar is refused too, though the port schema refuses it first as D001, so in practice it never reaches
this rule. `at` is `operations/<op>/accepts/<field>/resolves`. The port is not registered, so
everything that runs it is refused as well, usually R001. This is a broken plugin, not a broken tree: a tree's author
meets it only through a plugin under development. What the path finds in the tree's own documents is judged where the
tree names them.

## Example

Take `static` off the `store` input of `@storage/store.port.json#get`:

```
D011  @storage/store.port.json#operations/get/accepts/store/resolves
    'store' resolves a type but is not static
    → a resolved type is read before anything runs, so 'store' must be a literal: add "static": true
R001  @features/customers/data/kept-get-postgres.graph.json#nodes/storedCustomer/run
    unknown port '@storage/store.port.json'
    → wilanis ls port
```

Resolve through a key no input gives:

```
D011  @storage/store.port.json#operations/get/accepts/store/resolves
    $T resolves through 'collections[absent].of', which takes a key by 'absent', not an input of this operation
    → accept 'absent', or name one of: store, collection, key, scope
```

## Fix

In the plugin's port document: mark the resolving input `"static": true`, take the key by an input the operation
accepts and mark that one static too, or rewrite the path in the grammar the hint spells. The R001s that follow go
with it.
