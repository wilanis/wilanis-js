# T010

- **Family:** T -- triggers
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/delivery.ts`
- **Proved by:** `packages/runtime/test/sabotage-delivery.test.ts` (`T010 a connection whose kind declares no
  delivery`, `T010 a connection path that names no document`, `T010 a connection read rather than written as a path`)

## Refuses when

A trigger whose kind declares `connection` receives from the connection the setting of that name holds, and that
setting does not name a connection that delivers messages. It is refused at the setting in three cases: it is a
read (`{{secrets.jwt}}`) rather than a path written as a literal, since which broker a trigger receives from is
decided when the tree is checked; it names no connection document of the tree; or it names a connection whose kind
declares no `delivery`, such as an HTTP upstream or a directory, which hands a trigger nothing. A setting that is
absent or not a string is T001's, and a connection whose own kind is unknown is that connection's R001.

Where T010 refuses, T009 is not asked: nothing is delivered, so nothing is delivered twice.

## Example

Point `remove-queued.trigger.json` at the customers' HTTP upstream instead of the broker:

```
T010  @features/customers/edge/remove-queued.trigger.json#settings/connection
    '@connections/customers-api.connection.json' is a connection of kind '@http/http.connection-kind.json', which declares no delivery: it hands a trigger no messages
    → receive from a connection whose kind declares delivery; wilanis ls connection-kind
```

A path that names no document is `settings.connection names no connection: '@connections/nope.connection.json'`,
with `wilanis ls connection` in the hint; a read is `settings.connection reads {{secrets.jwt}}, but the connection a
trigger receives from is written as its path`.

## Fix

Write, as a literal, the path of a connection whose kind declares `delivery` (in development, one of kind
`@queue-memory/memory.connection-kind.json`, which delivers at least once). `wilanis ls connection` lists the tree's connections and
`wilanis ls connection-kind` the kinds its plugins grant. If no connection of the tree is a broker, add one at
`connections/` naming such a kind.
