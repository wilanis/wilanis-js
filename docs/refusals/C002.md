# C002

- **Family:** C -- connections, settings and stores
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/contracts.ts`, `packages/compiler/src/check/project.ts`
- **Proved by:** `packages/runtime/test/sabotage-project.test.ts` (`C002 a throttle that is not a number`)

## Refuses when

Settings do not fit the type that declares them. A connection's `settings` are judged against the `settings` of its
connection kind (`contracts.ts`, at `settings`), and a plugin's settings in `project.json` against the `settings`
its `plugin.json` declares (`project.ts`, at `plugins/<n>/settings`). The message is the first mismatch, a path of
fields down to the value. A trigger's settings that do not fit its kind are T001, not this.

## Example

Make the throttle of the customers API connection a word:

```
C002  @connections/customers-api.connection.json#settings
    settings: field 'throttle': field 'concurrency': "four" is not number
    → wilanis describe @http/http.connection-kind.json
```

The plugin form, with `@http`'s `port` set to `"eighty"`:

```
C002  @project.json#plugins/2/settings
    plugin '@http' settings: field 'port': "eighty" is not number
    → wilanis describe @http/plugin.json
```

## Fix

Run the `wilanis describe` the hint names to read the declared settings, and write the value the field's type asks
for. A plugin may judge the same setting further in its own `check` (the throttle above is also X003).
