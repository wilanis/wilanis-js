# C014

- **Family:** C -- connections, settings and stores
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/project.ts`
- **Proved by:** `packages/runtime/test/sabotage-project.test.ts` (`C014 a blob registry behind a connection no plugin offers a blob store for`)

## Refuses when

`project.json → blobs.connection` names something that cannot keep the blob registry's bytes: no connection at all,
or a connection of a kind for which no plugin the project names offers a blob store (a module's `blobStores`). It
points at `blobs/connection`.

## Example

Put the blob registry behind the customers API, an `@http` connection:

```
C014  @project.json#blobs/connection
    blobs.connection names '@connections/customers-api.connection.json', of kind '@http/http.connection-kind.json', and no plugin the project names offers a blob store for that kind
    → wilanis ls connection-kind; name a plugin that offers a blob store for one, or remove blobs.connection to keep files
```

A name that is no connection says `blobs.connection names '<ref>', which is no connection`, with the hint
`wilanis ls connection`.

## Fix

Name a connection whose kind a plugin of the project offers a blob store for, adding that plugin to `plugins` if
needed, or remove `blobs.connection` and the registry keeps files on disk.
