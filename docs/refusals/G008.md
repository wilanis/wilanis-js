# G008

- **Family:** G -- graphs
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/graph-whole.ts`
- **Proved by:** `packages/runtime/test/sabotage.test.ts` (`G008 a node nobody reads`)

## Refuses when

Something a graph declares is read by nothing: a field of its `in` shape no value reads, unless `in` is read whole
(`in.<field> is read by no edge`, at `in`); a constant no value reads (at `constants/<name>`); or a node whose answer no
other node reads and `out.from` does not name (`node '<id>' is read by nothing`, at `nodes/<id>`). A switch is never
refused this way, since it routes rather than answers. Where the unread node is an effect no switch routes, the hint
says it runs on every branch: two writes placed beside a switch meant to choose between them both run on every call.

## Example

Point `digest`'s `out.from` at `all` instead of `digest`, and the node that was the answer is read by nothing:

```
G008  @features/customers/domain/digest.graph.json#nodes/digest
    node 'digest' is read by nothing
    → wire its result into another node, or name it in out.from
```

The same sabotage changes what the graph answers, so each binding that meets `digest` with it is refused as B005.
An unread constant reads `constant 'spare' is read by no edge`, with the hint `read it as {{const.spare}}, or remove
it from constants`.

## Fix

Wire what is declared into the node that needed it, or remove it: a field from the `in` shape, a constant from
`constants`, a node from `nodes`. An effect meant for one branch becomes the `to` of that switch's rule, so it runs
only there; an effect whose answer nobody needs but that must run on every branch is read from every branch or named in
`out.from`.
