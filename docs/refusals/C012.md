# C012

- **Family:** C -- connections, settings and stores
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/scopes.ts`
- **Proved by:** `packages/runtime/test/sabotage-scoping.test.ts` (`C012 says a literal is not a read, and writes the two entries that would make one`); `packages/runtime/test/sabotage-scoping.test.ts` (`C012 a scope reading a name the store does not bind`)

## Refuses when

A `scoped` column of a store's collection is not filled by exactly one well-formed read. A scope is a column the
store keeps beside the record, and its value is `{{name}}` of one resolver the store binds under `reads`, and nothing
else. It is refused, at `collections/<name>/scoped/<column>`, when the value is not a whole read (a literal, an
interpolation, a field of a read, or `{{in.…}}`); when it reads a name the store does not bind; when the column is a
field of the collection's shape, since a field is written by whatever made the record and could have come from the
caller; when the bound resolver is not declared `required`, since a scope is read as present; and when the read is
not a string or a number, as a list, or a claim or session attribute that types `unknown`, is not. Whether the guard
hands the read at all is A007.

## Example

Scope the example's customers by a literal:

```
C012  @features/customers/data/customers.store.json#collections/customers/scoped/tenant
    'acme' is not a read; a scope is exactly one resolver the store binds under reads
    → write "scoped": { "tenant": "{{tenant}}" } and bind tenant: "reads": { "tenant": "@<feature>/edge/<file>.resolvers.json#tenant" }
```

The store's `tenant` entry is then read by nothing, so a P005 follows it; it goes when the scope reads it again.

## Fix

Write the two entries the hint spells: the column as `{{<name>}}`, and the name bound under the store's `reads` to a
resolver in an `edge/` resolvers document. Rename a column that collides with a field of the shape. Declare the
resolver `required`, and read an attribute that types as a string or a number: for a session attribute, declare it in
the shape the guard's `settings.session` names.
