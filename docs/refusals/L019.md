# L019

- **Family:** L -- layers, effects and visibility
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/provided.ts`
- **Proved by:** `packages/runtime/test/site.test.ts` (`L019 a domain operation marking a field provided`, `L019 a
  shape marking a field provided`, `L019 a native operation's provided field typed string, marked secret, or
  optional`)

## Refuses when

A field is marked `provided` where the compiler cannot provide it, or as something other than what it provides
(RFC 0032). `provided: site` belongs on a field of a native operation's `accepts`, and that field is
`@std/Site.shape.json`, not secret, and required. Four forms:

- a domain operation's field carries `provided` (at `operations/<name>/accepts/<field>`): a domain operation is met by
  a binding, so the site is the native operation's to ask for, where the binding runs it;
- a shape's field carries `provided` (at `fields/<field>`): a shape is a type, not a call, so there is no site;
- a native operation's provided field is not `@std/Site.shape.json`: the compiler writes two strings, `file` and `at`,
  and the checker types the field against that shape;
- a native operation's provided field is `secret`, or `required: false`: the site is two public strings every report
  shows, and the compiler writes it at every site, so no author can leave it out.

## Example

Mark a `site` field of the customers port's `get` provided:

```
L019  @features/customers/domain/customer.port.json#operations/get/accepts/site
    domain operation 'get' marks 'site' provided -- a domain operation is met by a binding; the site is a native operation's to ask for
    → drop provided, or ask for the site in the native operation the binding runs
```

Type a native operation's provided field as a string:

```
L019  @note/note.port.json#operations/record/accepts/site
    native operation 'record' marks 'site' provided, but its type is not @std/Site.shape.json
    → a provided site is @std/Site.shape.json, never secret, always given
```

## Fix

On a domain operation or a shape: drop `provided`, and declare the site on the native operation the binding runs.
On a native operation: type the field `@std/Site.shape.json`, drop `secret`, and leave `required` at its default.
