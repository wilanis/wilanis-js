# D006

- **Family:** D -- documents
- **Status:** live, since 0.1.0
- **Made in:** `packages/core/src/load.ts`, `packages/core/src/documents.ts`, `packages/runtime/src/project.ts`
- **Proved by:** `packages/runtime/test/plugin-packages.test.ts` (`D006 when from is not a package name, or names a package that is not installed`, `D006 when a plugin ships no plugin.json`)

## Refuses when

A plugin the project names under `project.json → plugins` cannot be had. Each entry gives the plugin's root in `use`
and, for anything but the built-in `@std` and `@cli`, the npm package that ships it in `from`. The forms, all on
`project.json`:

- `use` names a plugin that is not available here (`at` is `plugins/<index>`; the hint lists the ones that are);
- `from` is not an npm package name, such as a file path (`plugins/<index>/from`);
- the package cannot be imported, usually because it is not installed (the hint is `npm install <from>`);
- the package does not export a `PluginModule` as its default;
- the package is another plugin than `use` says (the hint gives the right `use`);
- the plugin has no documents at the `docs` directory it points to, or ships no `plugin.json` there.

A plugin whose package failed to load is reported once, with the install hint, and not a second time as unknown.

## Example

Name a plugin nothing provides:

```
D006  project.json#plugins/11
    unknown plugin '@nope'
    → available here: @std, @cli, @http, @blob, @reload, @auth, @schedule, @storage, @storage-memory, @storage-postgres, @otel. A plugin package is named by "from" in project.json
```

Name one by a file path, which the project's schema also refuses as D001, and `wilanis check` adds:

```
D006  project.json#plugins/1/from
    '../evil.js' is not an npm package name
    → from names a published package, never a file path
```

## Fix

Give `from` the published package name and install it (`npm install <from>`), or correct `use` to the root the
package declares. A plugin that ships no `plugin.json`, or whose `docs` directory is missing from its package, is a
broken package: its `files` must list the docs directory.
