# G023

- **Family:** G -- graphs
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/graph-nodes.ts`
- **Proved by:** `packages/runtime/test/sabotage-catch.test.ts` (`refuses the target reading it, at the value that does`)

## Refuses when

The node a caught fault is routed to, or a node that runs behind it, reads the node that broke. It broke, so it
produced nothing to read. The message says whether the reader is the target itself (`whose fault routed here`) or runs
behind it (`whose fault routed to '<target>', which this node runs behind`). Each value that reads it is refused on its
own, at `nodes/<reader>/in/<name>`, or at `nodes/<reader>/over` for a map.

## Example

Have `get-row`'s `unreachable`, where the switch routes `fetched`'s fault, say the status it got:

```
G023  @features/customers/data/get-row.graph.json#nodes/unreachable/in/message
    reads 'fetched', whose fault routed here: it produced nothing
    → say it without the value; the report and the trace carry what fetched threw
```

## Fix

Say it without the value: `the customer API could not be reached`. What the node threw is in the run's report and its
trace.
