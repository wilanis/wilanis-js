# G012

- **Family:** G -- graphs
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/graph-nodes.ts`
- **Proved by:** `packages/runtime/test/sabotage-project.test.ts` (`G012 a map over something that is not a list`)

## Refuses when

A `map` node's `over` reads something that is not a list (`over is <type>, not a list`, at `nodes/<id>/over`), or its
`bind` names a path the element does not hold (`bind.<name>: <why>`, at `nodes/<id>/bind/<name>`). A map runs its
operation once per element of a list and hands each element as `item`, or through `bind` as named inputs.

## Example

Make `remove-customers` take a single string rather than a list of ids:

```
G012  @features/customers/domain/remove-customers.graph.json#nodes/removed/over
    over is string, not a list
    → map runs over a list; read one, or use a run node
```

A G005 follows, since the element no longer binds the `id` the operation requires, and each binding that meets
`removeMany` with the graph is refused as B005.

## Fix

Point `over` at a list, or, when one value is meant, use a `run` node instead of a `map`. A `bind` path names a field
the element holds; `""` binds the element itself.
