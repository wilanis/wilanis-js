# C006

- **Family:** C -- connections, settings and stores
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/stores.ts`
- **Proved by:** `packages/runtime/test/sabotage-storage.test.ts` (`C006 a reference of one type to records keyed by another`)

## Refuses when

A reference's field holds a type other than the key of the collection it names. What a reference holds is the key
of the record it points at, so the two types are the same. It points at `collections/<name>/refs/<field>`. A field
no engine holds a value of is C008 and is not judged again here.

## Example

Plant a collection keyed by a number and refer a string field to it:

```
C006  @features/customers/data/customers.store.json#collections/customers/refs/email
    'email' is string, and it refers to records keyed by number
    → email is string; @customers/domain/Counted.shape.json is keyed by number
```

## Fix

Refer from a field of the key's type, change the field's type to it, or name the collection the field actually
holds keys of.
