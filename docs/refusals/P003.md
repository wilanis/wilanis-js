# P003

- **Family:** P -- static fields and resolvers
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/resolvers.ts`
- **Proved by:** `packages/runtime/test/sabotage-reads.test.ts` (`P003 a resolver named like a root`)

## Refuses when

A resolver in a `resolvers` document is named `in`, `const`, `request` or `secrets`. Those are the roots every value
reads from, and a resolver is read as `{{name}}`, so one of those names would mean two things at once. The refusal
sits at `resolvers/<name>`. The same rule for the local name a document binds under `reads` is P006.

## Example

```
P003  @features/customers/edge/request.resolvers.json#resolvers/in
    resolver name 'in' is reserved
    → in, const, request and secrets are roots; pick another name
```

## Fix

Rename the resolver for what it reads (`host`, `agent`, `sid`), and every `reads` entry that names it.
