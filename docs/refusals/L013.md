# L013

- **Family:** L -- layers, effects and visibility
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/graph.ts`
- **Proved by:** `packages/runtime/test/sabotage-catch.test.ts` (`refuses a domain graph's switch that declares
  catch, and judges nothing more of it`)

## Refuses when

A domain graph's `switch` declares `catch`. What an effect breaking means is the data layer's, where the effect runs;
a domain graph says what is done and catches nothing. The catch is refused whole at `nodes/<id>/catch`, and nothing
more of it is judged: G021 to G025 apply to a data graph's catch only.

## Example

Give the `tierGiven` switch of the customers `list-customers` domain graph a catch:

```
L013  @features/customers/domain/list-customers.graph.json#nodes/tierGiven/catch
    domain graph's switch 'tierGiven' declares catch
    → the domain says what is done; what an effect breaking means is the data layer's: catch it in the data graph that runs the effect
```

## Fix

Remove `catch` from the domain graph, and catch the fault in the data graph that runs the effect: a switch there
routes the broken node to a `refuse` of a reason, and the domain sees a refusal it can route on like any other.
