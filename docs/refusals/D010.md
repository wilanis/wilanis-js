# D010

- **Family:** D -- documents
- **Status:** live, since 0.1.0
- **Made in:** `packages/core/src/load.ts`, `packages/runtime/src/project.ts`
- **Proved by:** `packages/runtime/test/sabotage-access.test.ts` (`D009 a local feature the include also ships; D010 an include that is not a tree, or one asking a feature it does not ship or a plugin the project lacks`)

## Refuses when

An entry under `project.json → includes` cannot be included as written. An include is an npm package holding a
wilanis tree, `project.json` and `features/`, and the host takes its features, its aliases and nothing else. The
forms, all on `project.json`:

- `from` is not an npm package name, or the package cannot be found from the project's `node_modules`
  (`includes/<index>/from`, the hint `npm install <from>`);
- the package has no `project.json`, so it is not a tree (`includes/<index>`);
- it ships no `features/` directory;
- `features` asks for a feature the package does not ship (`includes/<index>/features`, the hint lists those it
  does);
- the included tree uses a plugin the host's `project.json` does not name, since an include leaves its plugins
  behind and the host must provide them (`includes/<index>`, one refusal per plugin).

## Example

Ask the access tree for a feature it does not have:

```
D010  project.json#includes/0/features
    '@wilanis/access' ships no feature 'nope' (it ships access, access-dev)
    → name one of access, access-dev under includes[0].features
```

Drop `@cli` from the host's plugins, which the access tree uses:

```
D010  project.json#includes/0
    '@wilanis/access' uses plugin '@cli', which this project does not name
    → add { "use": "@cli" } to project.json → plugins, with the settings its README says
```

## Fix

For a plugin, add it to the host's `plugins`, with `from` and the settings the include's README asks for. For a
feature, name one the package ships. For a package that is not found or not a tree, install it, or correct `from` to
the package that holds the tree. A host whose own `project.json` did not load (D000, D005) meets this rule for every
plugin of the include; fix that first.
