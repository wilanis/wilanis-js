# C016

- **Family:** C -- connections, settings and stores
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/contracts.ts`
- **Proved by:** `packages/runtime/test/sabotage-limits.test.ts` (`refuses it on a shape's field that is not a list, at the maxItems`)

## Refuses when

A field says `maxItems` but its type is not a list. `maxItems` bounds a list and nothing else. It is judged on a
shape's `fields`, on a port operation's `accepts` and on the fields of an inline `returns`, at any depth of inline
objects, and points at the field's `maxItems`. A field whose type does not resolve is R001's and is not judged here.

## Example

Bound the example's `ListRequest.tier`, a string:

```
C016  @features/customers/edge/ListRequest.shape.json#fields/tier/maxItems
    field 'tier' says maxItems but is string, not a list
    → maxItems bounds a list; this field is string: drop maxItems, or make the field a list
```

## Fix

Drop `maxItems`, or make the field a list if it was meant to be one.
