# C004

- **Family:** C -- connections, settings and stores
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/stores.ts`
- **Proved by:** `packages/runtime/test/sabotage-storage.test.ts` (`C004 a default the field would not accept, or one given for the key`)

## Refuses when

A collection's `defaults` gives a field a value its type would not accept, or gives the key a default at all. A
default is what an added column gives the rows already there, so it is a literal of the field's type; and a key
identifies a record, so it is never defaulted. It points at `collections/<name>/defaults/<field>`. A default for a
field the shape lacks is C003.

## Example

Default the example's `tier`, a string, to a number:

```
C004  @features/customers/data/customers.store.json#collections/customers/defaults/tier
    tier: expected string
    → write a literal of type string; a key is never defaulted
```

A default on the key says `'id' keys this collection, and a key is never defaulted`.

## Fix

Write a literal of the type the hint names, or drop the entry. Drop a default on the key: every record is written
with one.
