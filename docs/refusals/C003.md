# C003

- **Family:** C -- connections, settings and stores
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/stores.ts`
- **Proved by:** `packages/runtime/test/sabotage-storage.test.ts` (`C003 a constraint naming a field the shape does not have, pointing at the constraint that named it`)

## Refuses when

A store's collection names, in `unique`, `refs` or `defaults`, a field its shape (`of`) does not have. Each
constraint is refused where it is written: `collections/<name>/unique/<i>`, `collections/<name>/refs/<field>` or
`collections/<name>/defaults/<field>`. The message lists the fields the shape has.

## Example

Misspell a field in the example store's `unique`:

```
C003  @features/customers/data/customers.store.json#collections/customers/unique/1
    'emaill' is not a field of @customers/domain/Customer.shape.json (fields: id, name, email, tier, registrar, active, note)
    → wilanis describe @customers/domain/Customer.shape.json
```

## Fix

Name a field from the list the message gives, or add the field to the shape if the collection is meant to hold it.
