# I008

- **Family:** I -- invariants
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/invariant-writes.ts`
- **Proved by:** `packages/runtime/test/sabotage-invariant-writes.test.ts` (`I008 a record written out field by field,
  at the record`, `I008 says nothing judges the record, naming the invariant, and hints where to make it`, `none for
  the record read whole from in`)

## Refuses when

A node runs `@storage/store.port.json#put` over a collection whose shape a field invariant holds over, and its
`record` is anything but one whole read of `in` or of a node of the graph: an object written out at the write, a
field of another value (`{{stored.record}}`, `{{in.customer}}`), or a string with more than one read in it. The
collection's shape is the `$T` the call's `store` resolves. The refusal sits at `nodes/<id>/in/record`, and the
message names the shape and the invariant.

A record composed at the write is a value no site ever held, so the compiler has nowhere to put the guard RFC 0007
lowers: it would stand at the first node that reads the stored record, after the store has kept it. Read whole from
`in` or from a node, the record is a value the graph took or made before the write, and judged there. `"record":
"{{in}}"` over a graph whose `in` is the shape is the form the example's `keep-customer` takes.

## Example

```
I008  @features/customers/data/keep-customer.graph.json#nodes/stored/in/record
    the Customer written here is composed at the write, so nothing judges it against 'A customer is reachable' (@features/customers/domain/a-customer-is-reachable.invariant.json) before the store keeps it
    → make the Customer whole before the write -- @std/object.port.json#make with "type": "@features/customers/domain/Customer.shape.json", in a domain graph that hands it to this one as in -- and give #put "record": "{{in}}"
```

## Fix

Make the record where it can be judged and hand it to the write whole. A domain graph makes it with
`@std/object.port.json#make` (or `#merge`, laying a change over the record as kept) and passes it to an operation that
takes the whole shape; the data graph behind that operation takes it as its `in` and writes `"record": "{{in}}"`. The
guard at that `in` judges the value again before the write, whoever the caller is.
