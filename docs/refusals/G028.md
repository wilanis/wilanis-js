# G028

- **Family:** G -- graphs
- **Status:** live, since 0.1.0
- **Made in:** `packages/compiler/src/check/within.ts`, called from `packages/compiler/src/check/inputs.ts`
- **Proved by:** `packages/runtime/test/within.test.ts` (`G028: a path within the element is typed`)

## Refuses when

A call site gives a path that the operation's contract cannot read. A native contract may mark a static string field
`within: "$T"` (RFC 0039). The field's literal is then a dotted path within the type `$T` is bound to at this call,
and the operation reads each element at that path. The contract may also say `reaches`: the type the value at the
end of the path must have. The checker refuses the path when:

- the bound type does not hold it (a field it does not have, or a step into a value that is not an object);
- it passes through a field that may be missing, so some elements would have nothing there;
- it ends at a value that is not of the `reaches` type.

The refusal sits at the field that gives the path: `nodes/<id>/in/<field>` in a graph, `operations/<name>/in/<field>`
in a binding's delegation. A read written where the path goes is P001, as for any static field, and this rule says
nothing more about it.

## Example

Total a list of orders by a field the order does not have:

```
G028  @features/orders/domain/total.graph.json#nodes/tiers/in/by
    by: 'teir' is not a field of @features/orders/domain/Order.shape.json
    → name a required string field of the element: tier, buyer.name
```

A path through an optional field says `passes through a field of ... that may be missing`, and a path to a value of
the wrong type says `'tier' is string, not number`.

## Fix

Write one of the paths the hint lists: each is required at every step and ends at the type the operation wants. If
the field you meant is optional, make it required in the shape.
