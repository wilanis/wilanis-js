1 · WHAT WILANIS IS

Let agents write your backend, and a compiler refuse what they get wrong before it runs.

A language for programs made of effects, written as JSON documents, with a compiler that judges the whole tree before anything runs.

The compiler reads every file and proves they fit together. A small engine runs what it approved. Everything that touches the world (a route, a command, a clock, a file, a database) is a plugin behind a port the tree declares.

    wilanis check

    148 ways a tree can be wrong, all found before anything runs

    Every refusal names the file, the JSON path inside it, and the edit that fixes it. It judges every profile at once, so the production wiring is checked on a laptop with no database.

    • LLayers and effects 12a business graph calling the database, a lock inside a transaction
    • GGraphs 24an effect that runs on every branch, a retry on a POST
    • AAccess 8a route reading the tenant with nothing proving who is calling
    • IInvariants 6a new write route that skips the rule every other route follows
    • TTriggers 10a refusal the route can reach but never maps to a status
    • BBindings and profiles 12a port nobody implements under production
    • CConnections and stores 19a unique constraint on a field the shape lacks
    • PStatic fields and resolvers 6a request header read where the request never arrives
    • DDocuments 12a trigger filed in the data layer
    • XPlugin rules 35a session write outside the session shape, a cron that is not one
    • SScenarios 3a recorded run pinning a refusal that never happened
    • RReferences 1a path to a document that does not exist

    Example refusal · L009

    A Redis lease inside a database transaction

    Registering a customer writes two rows in one "atomic": true graph. Suppose someone adds a Redis lease so two registrations of the same tier never race:

    {
  "id": "tierLease",
  "run": "@redis/lease.port.json#acquire",
  "in": { "key": "tier:{{in.tier}}", "ttlMs": 5000 }
}

    The transaction can roll back. The lease cannot. If the second write fails, the rows vanish and Redis still says the tier is held for five seconds. Check, 0.64 s:

    G008  @features/customers/data/store-and-latest.graph.json#nodes/tierLease
    node 'tierLease' is read by nothing
    → nothing routes to 'tierLease', so it runs on every branch: make it the 'to' of a switch rule, or read its answer from every branch
L009  @features/customers/data/store-and-latest.graph.json#nodes/tierLease
    atomic graph '@features/customers/data/store-and-latest.graph.json' reaches '@redis/lease.port.json#acquire', which cannot take part in a transaction (profile 'local')
    → read or send that outside the transaction: in the caller for a domain graph, in a graph of its own for a data graph

    atomic graph '@features/customers/domain/register-all.graph.json' reaches '@redis/lease.port.json#acquire', which cannot take part in a transaction (profile 'local')

    What unit tests usually hold

    • the handler calls the right repository
    • types line up across layers
    • each if branch is reached
    • the 401 fires without a token
    • the output did not change

    Who holds it in a wilanis tree

    • no handler exists; check proves the wiring
    • check, under every profile
    • rehearse, which solves for each rule
    • check (A, T) and rehearse
    • regress, naming the node that moved

    A tree has no code of its own to unit-test. The code lives in plugins, tested once in their own packages. What rehearsal cannot tell you is how the real Postgres or upstream API answers, since it stubs them; that stays an integration test.

    Glossary

    The words on this page

    Atomic graph
    A graph marked "atomic": true. Its writes commit or roll back together, and check refuses anything inside it that cannot roll back.
    Binding
    How a domain port is met. The profile chooses which binding runs.
    Check
    wilanis check: the compiler judging the whole tree, under every profile, before anything runs.
    Codec
    Turns a body into a value and back. @http maps each content type to a codec; a route picks one with consumes and produces.
    Compiler
    Reads every document, proves they fit together, and hands the engine what passed.
    Connection
    A document in connections/ naming something outside: a database, an API, a broker.
    Data graph
    A graph in data/. It reaches the effects: stores and native ports.
    Domain graph
    A graph in domain/. Business rules, pure; it calls ports.
    Domain port
    The operations a feature offers. Triggers fire them, bindings meet them.
    Engine
    Small and stateless. Runs what the compiler approved.
    Feature
    A directory under features/, split into edge/, domain/ and data/.
    Fuzz
    Records runs as scenarios.
    Guard
    The one plugin (@auth) that verifies a credential before any graph runs and adds the caller to the context.
    Include
    Another tree brought in as an npm package, such as @wilanis/access.
    Invariant
    A rule stated once that the whole tree is held to: over port operations, or over a shape's fields.
    Layer
    edge/, domain/ or data/. The directory is the layer.
    Native port
    A port a plugin grants and its code meets: a store, an HTTP request.
    Plugin
    A package that grants ports, trigger kinds, codecs and connection kinds. The code that touches the world.
    Policy
    A document in edge/ that fires a domain operation and maps its refusal to deny or challenge.
    Port
    A document declaring operations and the shapes they take and answer.
    Profile
    A named wiring (local, live, production) that chooses bindings and connections.
    Refusal
    A run ending on purpose with a reason; and a check finding, with a code, a file, a path and a fix.
    Regress
    Replays recorded scenarios and diffs them node by node.
    Rehearse
    Fires every trigger with stubbed effects and solves inputs for every branch.
    Resolver
    A named read of the request, in edge/. Nothing runs.
    Scenario
    One recorded run: its inputs, each node's answer, the output.
    Shape
    A document declaring fields and their types.
    Startup step
    What project.json → startup runs on wilanis start. listen is one.
    Store
    A document saying how records are kept, and how they are scoped.
    Tree
    A project: project.json, features/ and connections/, all JSON.
    Trigger
    One file in edge/ that fires one domain operation. It never names a graph.
    Trigger kind
    Granted by a plugin (@http, @cli, @queue, @schedule): the settings a trigger takes and the context it hands.
